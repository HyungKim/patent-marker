★먼저읽기 — Windows 설치 순서

이 파일은 안내용 바로가기입니다. 자세한 따라하기 가이드는 아래 문서를 여세요.

  · GitHub 화면에서 보기:  docs 폴더 → 00_Windows_따라하기_가이드.md
  · 압축을 푼 뒤 PC 에서 보기:  docs\00_Windows_따라하기_가이드.md (VS Code 나 메모장으로 열기)

GitHub 에서 내려받은 경우 요약 (★ 처음 설치할 때):
  1) 초록 Code 버튼 → Download ZIP → C:\ 에 풀기 → 폴더명을 patent_marker 로 변경
  2) setup.bat 더블클릭 (인터넷 필요 · Python·Ollama·모델 5GB 자동 설치)
  3) run.bat 더블클릭 → PPTX 를 C:\patent_marker\input 폴더에 복사 → 브라우저 목록에서 클릭 → 분석 시작
     (회사 PC 처럼 브라우저 업로드가 막혀 있어도 됩니다. 결과는 output 폴더에 저장됩니다)
     브라우저 없이 쓰려면: PPTX 를 mark.bat 아이콘 위에 끌어다 놓기
     (기본 모델은 가벼운 qwen3:8b — GPU 없는 PC 도 이대로 하면 됩니다)

USB 로 받은 15GB 압축본(offline_bundle 포함)을 쓰는 경우에는 setup.bat 대신
setup_offline.bat 을 실행하면 인터넷 없이 설치됩니다.

이미 설치된 PC 를 새 버전으로 바꿀 때는 위 1)~3) 을 따라 하지 마세요.
폴더를 새로 만들지 않고 안의 파일만 덮어쓰는 별도 절차가 있습니다.
  → docs\00_Windows_따라하기_가이드.md 의 [7-1] 새 버전으로 바꾸기

  요약: 프로그램을 완전히 끄기 → Download ZIP → 풀린 patent-marker-main 폴더의
        '안의 내용물 전부' 를 기존 C:\patent_marker 에 덮어쓰기 → run.bat 다시 실행.
        setup.bat 은 다시 돌리지 않습니다. review_data 와 .venv 는 그대로 보존됩니다.
