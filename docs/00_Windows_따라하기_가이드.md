# Windows PC 로 옮겨서 실행하기 — 따라하기 가이드

이 문서에 적힌 대로만 하면 됩니다. 위에서부터 순서대로, 한 단계가 끝난 것을 확인한 뒤 다음으로 넘어가세요.
"만약 ~" 으로 시작하는 줄은 그 상황일 때만 보면 됩니다. 그 밖의 상황은 맨 아래 "문제가 생기면" 을 보세요.

전체 흐름:  [0] 준비물 확인 → [1] USB 에 복사 → [2] Windows PC 에 압축 풀기 → [3] 설치 → [4] 실행 → [5] 첫 테스트 → [6] 종료
소요 시간:  준비·복사 30분 + 설치 15분 + 첫 테스트 10분~1시간(PC 성능에 따라)


──────────────────────────────────────────────────────────────
※ USB 가 아니라 GitHub 에서 내려받는 경우 (그 PC 에 인터넷이 될 때)
──────────────────────────────────────────────────────────────

  [1][2] 단계 대신 아래처럼 하고, [3] 에서는 setup_offline.bat 대신 setup.bat 을 씁니다.

  1. Windows PC 브라우저에서 저장소 주소(github.com/계정이름/patent-marker)에 접속합니다.
  2. 초록색  "Code"  버튼 → "Download ZIP" 을 누릅니다. (patent-marker-main.zip 이 받아짐)
  3. 내려받은 zip 을 우클릭 → "압축 풀기..." → 경로 칸에  C:\  입력 → 압축 풀기.
  4. 생긴 폴더  C:\patent-marker-main  을 클릭하고 F2 키 → 이름을  patent_marker  로 바꿉니다.
  5. 그 안의  setup.bat  을 더블클릭합니다. (GitHub 저장소에는 15GB 설치 꾸러미가 들어 있지 않아,
     Python·Ollama·모델 5GB 를 인터넷으로 자동 설치합니다. 모델 다운로드가 수십 분 걸릴 수 있습니다.
     마지막 [5/5-2] 에서 "빠름" 모델(약 2.5GB)도 받습니다 — 실패해도 설치는 끝나고, 정밀 모드는 그대로 됩니다.)
     회사 PC 에서 [2/5] 라이브러리 설치가 SSL 오류로 실패하면 인증서 확인을 건너뛰고 자동으로
     한 번 더 시도합니다. 그래도 멈추면 → "문제가 생기면" 의 U 항목.
  6. 이후는 [4] 실행 단계부터 아래와 완전히 동일합니다.


════════════════════════════════════════════════════════════════════
[0] 시작하기 전에 확인  (Windows PC 에서, 5분)
════════════════════════════════════════════════════════════════════

  [ ] Windows 10 (버전 22H2 이상) 또는 Windows 11,  64비트
        확인: 시작 → 설정 → 시스템 → 정보(또는 '정보' 검색)
              "Windows 사양" 의 버전,  "시스템 종류" 가 "64비트 운영 체제" 인지
  [ ] 메모리(RAM) 16GB 이상
        확인: 같은 '정보' 화면의 "설치된 RAM"
  [ ] C 드라이브 여유 공간 40GB 이상
        확인: 파일 탐색기 → 내 PC → C: 드라이브 아래 "여유 공간"
        (압축 파일 15GB + 압축 푼 폴더 15GB + 모델 복사본 14GB 가 한때 같이 있게 됩니다.
         설치가 끝난 뒤 압축 파일은 지워도 됩니다.)
  [ ] USB 메모리 32GB 이상,  파일 시스템이 exFAT 또는 NTFS
        확인: USB 를 꽂고 파일 탐색기 → USB 드라이브 우클릭 → 속성 → "파일 시스템"
        만약 FAT32 라면: 4GB 넘는 파일을 담을 수 없어 15GB 압축 파일이 복사되지 않습니다.
          USB 안의 내용을 다른 곳에 옮겨 둔 뒤, USB 우클릭 → 포맷 → 파일 시스템: exFAT → 시작
          (USB 내용이 전부 지워집니다)
        만약 USB 대신 회사 공유 폴더로 옮길 수 있다면 그쪽이 더 빠르고 편합니다.
  [ ] (있으면 좋음) NVIDIA 그래픽카드
        확인: 시작 → '장치 관리자' 검색 → 디스플레이 어댑터 펼치기 → "NVIDIA ..." 가 있는지
        없어도 됩니다. 기본 모델(qwen3:8b)이 가벼워서 CPU 만으로도 실용적인 속도로 동작합니다.
  [ ] 이 Mac 의 바탕화면에 patent_marker_windows.zip 파일이 있는지 (약 15GB)


════════════════════════════════════════════════════════════════════
[1] 이 Mac 에서 USB 로 복사  (10~20분)
════════════════════════════════════════════════════════════════════

  1. USB 를 Mac 에 꽂습니다.
  2. 바탕화면의 patent_marker_windows.zip 을 USB 로 드래그합니다.
  3. 복사가 끝나면 USB 아이콘을 우클릭 → "추출(꺼내기)" 을 누른 뒤 뽑습니다.
     (복사 중에 뽑으면 파일이 깨집니다. 반드시 꺼내기 후에 뽑으세요.)


════════════════════════════════════════════════════════════════════
[2] Windows PC 에 압축 풀기  (10~20분)
════════════════════════════════════════════════════════════════════

  1. USB 를 Windows PC 에 꽂습니다.
  2. 파일 탐색기에서 USB 드라이브를 열고 patent_marker_windows.zip 을 찾습니다.
  3. 파일을 우클릭 → "압축 풀기..." 를 누릅니다.
     (Windows 11 은 우클릭 메뉴에 바로 보이고, Windows 10 은 우클릭 → "압축 풀기..." 입니다.
      만약 메뉴에 없으면 파일을 한 번 클릭해 선택한 뒤 위쪽 리본의 "압축 풀기" 를 누릅니다.)
  4. 작은 창이 뜨면, 경로 칸의 내용을 전부 지우고 아래 글자만 정확히 입력합니다.

         C:\

     그리고 "압축 풀기" 버튼을 누릅니다. 10~20분 걸립니다.
     만약 "이 폴더에 대한 액세스가 거부되었습니다 / 관리자 권한" 이라는 창이 뜨면 → "계속" 을 누릅니다.
     만약 그래도 안 되면 → 경로 칸에  C:\Users\본인윈도우사용자이름\  을 넣고 다시 풉니다.
       (이 경우 아래 설명의 C:\patent_marker 를 C:\Users\본인이름\patent_marker 로 읽으면 됩니다.)
  5. 끝나면 파일 탐색기 주소창에  C:\patent_marker  를 입력해 들어갑니다.
     아래 항목이 보이면 성공입니다.

         app              docs             offline_bundle   samples   tests   tools
         setup_offline.bat  run.bat   setup.bat   README.md   ...

     만약 C:\patent_marker 안에 또 patent_marker 폴더가 있다면 → 안쪽 폴더가 진짜입니다.
       안쪽 patent_marker 폴더를 C:\ 로 끌어다 옮기고(덮어쓰기), 빈 바깥 폴더는 지웁니다.

  ※ 압축 파일을 더블클릭해서 "열어 본 뒤" 안의 파일을 끌어다 놓는 방식은 쓰지 마세요.
     일부만 복사되거나 매우 느립니다. 반드시 "압축 풀기..." 메뉴를 쓰세요.
  ※ 바탕화면·문서 폴더에 풀지 마세요. OneDrive 동기화가 걸린 PC 에서 문제가 납니다.


════════════════════════════════════════════════════════════════════
[3] 설치  (15분 안팎 — 인터넷 필요 없음)
════════════════════════════════════════════════════════════════════

  C:\patent_marker 폴더에서  setup_offline.bat  을 더블클릭합니다.
  검은 창이 열리고 [1/5] ~ [5/5] 가 차례로 진행됩니다. 창을 닫지 말고 기다리세요.

  만약 더블클릭했는데 파란 창 "Windows 의 PC 보호" 가 뜨면 → "추가 정보" → "실행" 을 누릅니다.
  만약 백신 프로그램(V3, 알약 등)이 차단 메시지를 띄우면 → "허용" 또는 "예외 추가" 를 누릅니다.

  단계별로 보이는 것:

  [1/5] Python 확인
        - 이미 Python 3.11 이상이 있으면 "사용: ..." 한 줄만 나오고 넘어갑니다.
        - 없으면 Python 설치 창이 저절로 뜹니다. 진행 막대가 끝까지 가고 창이 닫힐 때까지
          아무것도 누르지 말고 기다립니다 (1~2분). 버튼을 눌러야 하는 창은 나오지 않습니다.
  [2/5] 가상환경 및 라이브러리
        - 1~2분. 글자가 주르륵 올라갑니다. "완료" 가 나오면 된 것입니다.
  [3/5] Ollama
        - 이미 있으면 넘어갑니다.
        - 없으면 Ollama 설치 창이 뜹니다. "Install" 버튼을 누르고 끝날 때까지 기다립니다 (1~3분).
          설치가 끝나면 화면 오른쪽 아래 작업 표시줄 구석에 라마(양) 모양 아이콘이 생깁니다.
          만약 "Welcome to Ollama" 같은 창이 뜨면 그냥 닫아도 됩니다.
  [4/5] 모델 파일 복사
        - 약 14GB 를 복사합니다. 2~10분. 아무 표시 없이 멈춘 것처럼 보여도 기다리세요.
  [5/5] Ollama 서버 기동 및 모델 확인
        - "모델 qwen3:8b 준비됨" 이 나오면 성공입니다.
        - 만약 Windows 방화벽 창("ollama.exe 가 네트워크에 접근하려 합니다")이 뜨면
          "액세스 허용" 을 눌러도, "취소" 를 눌러도 됩니다. (PC 안에서만 통신하므로 상관없음)

  마지막에  "설치 완료!  이제 run.bat 을 실행하세요."  가 보이면 아무 키나 눌러 창을 닫습니다.

  만약 중간에 "[실패] ..." 가 보이고 멈추면 → 그 줄의 글자를 그대로 적어 두고 "문제가 생기면" 을 보세요.
  만약 검은 창이 뜨자마자 사라지면 → "문제가 생기면" 의 A 항목을 보세요.


════════════════════════════════════════════════════════════════════
[4] 실행  (1분)
════════════════════════════════════════════════════════════════════

  1. C:\patent_marker 에서  run.bat  을 더블클릭합니다.
  2. 검은 창에 아래처럼 나옵니다. 이 창은 프로그램이 실행 중인 동안 계속 열어 둡니다.

         특허 마킹 도구  -  http://127.0.0.1:8765
         (이 창을 닫으면 프로그램이 종료됩니다)

  3. 3초쯤 뒤 브라우저(Edge 또는 Chrome)가 저절로 열립니다.
     만약 안 열리면 → 브라우저를 직접 열고 주소창에  127.0.0.1:8765  를 입력합니다.
  4. 화면 맨 위 상태줄을 봅니다.
       초록 점 "온디바이스 모델 qwen3:8b 준비됨 · 오프라인 동작"  → 정상입니다. [5] 로 갑니다.
       빨간 점 "Ollama 에 연결할 수 없습니다"                    → "문제가 생기면" 의 C 항목
       빨간 점 "모델 qwen3:8b 이 없습니다"                        → "문제가 생기면" 의 D 항목
     만약 Windows 방화벽 창("python.exe ...")이 뜨면 → 허용·취소 어느 쪽이든 됩니다.


════════════════════════════════════════════════════════════════════
[5] 첫 테스트 — 연습용 파일로 끝까지 돌려 보기
════════════════════════════════════════════════════════════════════

  1. 파일 탐색기에서  C:\patent_marker\samples\회사보고자료_예시.pptx  를 복사(Ctrl+C)해서
     C:\patent_marker\input  폴더에 붙여넣습니다(Ctrl+V).
     (input 폴더는 run.bat 을 처음 실행할 때 저절로 생깁니다. 없으면 [4] 를 먼저 하세요)
  2. 브라우저 화면의  "① input 폴더에서 고르기"  목록에 그 파일이 보입니다. 클릭합니다.
     (안 보이면 [새로고침]. 화면 아래에 "선택됨: 회사보고자료_예시.pptx" 가 뜨면 된 것입니다)
     ※ 파일을 넣는 방법은 이 밖에도 셋 더 있습니다 → [7-2]. 회사 PC 처럼 브라우저 업로드가
        막혀 있어도 ①~③ 은 됩니다.
  3. "모델" 은 정밀(기본) 그대로, 체크박스도 그대로 두고 오른쪽 아래의  "분석 시작"  을 누릅니다.
     ("빠름" 은 급한 문서를 초벌로 훑을 때만 — 약 3배 빠르지만 후보를 1/3 덜 잡고 A 등급이 없습니다.
      "빠름 … (미설치)" 로 회색이면 검은 창에서  ollama pull qwen3:4b-instruct  를 한 번 실행하면 됩니다)
  4. 진행 막대와 "슬라이드 N 분석 중 ... N분 NN초 경과 · 문단 읽는 중 / 답변 작성 중 N자" 글자가
     바뀌는 것을 확인합니다. 첫 슬라이드는 모델을 메모리에 올리느라 1~2분 더 걸립니다. 그 뒤 속도가 붙습니다.
     시간 제한은 없습니다 — 슬라이드 하나에 20~30분이 걸려도 프로그램이 끊지 않습니다.
       "문단 읽는 중"      = 모델이 슬라이드 글을 읽는 단계. 몇 분 동안 글자 수가 0 인 것이 정상
       "답변 작성 중 N자"  = 모델이 답을 쓰는 단계. 이 숫자가 늘고 있으면 살아 있는 것

     슬라이드 하나가 끝날 때마다 진행 막대 아래 회색 상자에 한 줄씩 쌓입니다:
       슬라이드 3 분석 완료 · 2분 10초 · 입력 2,187 / 출력 941 토큰 · 쓰기 4.1 토큰/초
     "쓰기 N 토큰/초" 가 이 PC 의 실제 속도입니다 (그래픽카드 없는 PC 는 보통 2~6). 이 숫자는
     PC 성능이고, 걸리는 시간은 "출력 토큰 ÷ 이 숫자" 입니다. 개선 전후 비교는 docs\05_개선_이력.md.

     예상 소요 시간 (연습용 5장 기준)
       그래픽카드 없음, run.bat (qwen3:8b) ............... 15~30분
       NVIDIA 그래픽카드 있음, run.bat ................... 2~10분

  5. 만약 "경과" 시간만 늘고 30분 넘게 "답변 작성 중" 의 글자 수가 한 번도 늘지 않으면:
       다른 프로그램(브라우저 탭 여러 개, 엑셀 등)을 모두 닫고 조금 더 기다려 봅니다.
       그래도 그대로면 "중단" 버튼(모델 호출 도중에도 바로 멈춥니다) → 검은 창을 닫음 →
       run.bat 더블클릭 → 다시 1번부터. (Ollama 가 저절로 꺼지면 "Ollama 서버가 사라져…" 로 알아서 멈춥니다)
  6. 끝나면 집계 카드(마킹 후보 N건 ...)와 목록이 보이고, 그 아래에
       저장됨: C:\patent_marker\output\회사보고자료_예시_특허마킹.pptx
     라고 적혀 있습니다. 결과는 이미 그 자리에 저장된 것입니다 (내려받기 불필요).
     집계 카드 바로 아래의 회색 한 줄 "이번 실행: 입력 … / 출력 … 토큰 · 쓰기 N 토큰/초 · 총 N분 · 인용구 일치 N/M · 버전 …" 은
     이 실행의 성적표이고, 같은 내용이 C:\patent_marker\review_data\run_log.tsv 에 한 줄씩 쌓입니다
     (엑셀로 열림 — 개선 전후를 숫자로 보고할 때 씁니다. 읽는 법은 docs\05_개선_이력.md 의 "측정 방법").
     "결과 폴더 열기" 를 누르면 탐색기가 그 파일을 선택한 채 열립니다.
     (브라우저 다운로드가 되는 PC 라면 "브라우저로 내려받기" 로 다운로드 폴더에 받아도 됩니다.
      같은 이름의 결과가 이미 있으면 (2), (3) 을 붙여 저장하고 덮어쓰지 않습니다)

[7-2] 파일을 넣는 네 가지 방법 — 브라우저 업로드가 막힌 PC 도 됩니다
════════════════════════════════════════════════════════════════════

  회사 PC 는 보안 정책으로 브라우저의 "파일 올리기" 가 막혀 있는 경우가 많습니다.
  이 프로그램은 브라우저와 같은 PC 에서 돌기 때문에, 파일을 브라우저로 올릴 필요 없이
  프로그램이 디스크에서 직접 읽으면 됩니다. 그래서 파일을 넣는 방법이 넷입니다.
  어느 하나가 막혀도 나머지로 됩니다. 결과는 어느 방법이든 C:\patent_marker\output 에 저장됩니다.

  ① input 폴더  (가장 확실 — 정책에 걸릴 요소가 없음)
     탐색기에서 PPTX 를  C:\patent_marker\input  에 복사 → 화면 "① input 폴더에서 고르기" 목록에서
     클릭 → 분석 시작.  목록이 안 바뀌면 [새로고침]. [폴더 열기] 를 누르면 탐색기가 input 폴더를 엽니다.

  ② 경로 붙여넣기  (복사할 필요 없이 원래 자리의 파일을 그대로 읽음)
     탐색기에서 파일을  Shift + 우클릭 → "경로로 복사"  → 화면의 입력칸을 클릭해 Ctrl + V →

  A. setup_offline.bat 을 더블클릭하면 검은 창이 뜨자마자 사라진다

  B. "[실패] offline_bundle\wheels 폴더가 없습니다"
     → 압축이 덜 풀렸거나 다른 폴더에서 실행한 것입니다.

     → 시작 메뉴에서 "Ollama" 를 찾아 실행합니다 (작업 표시줄 구석에 아이콘이 생김).
       브라우저에서 F5(새로고침). 그래도 빨간 점이면 검은 창을 닫고 run.bat 을 다시 더블클릭합니다.

  D. 화면 상단 빨간 점 "모델 qwen3:8b 이 없습니다"
     → 모델 복사가 안 된 것입니다. setup_offline.bat 을 한 번 더 실행하면 [4/5] 에서 다시 복사합니다.
       (GitHub 에서 받아 setup.bat 으로 설치한 경우: setup.bat 을 다시 실행하면 모델을 내려받습니다)
       확인 방법: 파일 탐색기 주소창에  %USERPROFILE%\.ollama\models\manifests  입력 →
       registry.ollama.ai\library\qwen3 안에 8b 파일이 있어야 합니다.

  E. "[실패] 휠 설치" 또는 "no matching distribution"
     → 이 PC 가 64비트 Windows 가 아니거나(32비트, ARM) Python 버전이 맞지 않는 경우입니다.
       [0] 의 "시스템 종류" 를 다시 확인하세요. 32비트/ARM PC 는 지원하지 않습니다.

     → 경로에 문제가 있을 가능성이 큽니다. 폴더를 C:\patent_marker 로 옮긴 뒤 다시 실행하세요.
       이미 C:\patent_marker 라면 .venv 폴더를 지우고 setup_offline.bat 을 다시 실행합니다.

  G. Python 설치 창에서 "Disable path length limit" 버튼이 보인다
     → 눌러도 되고 안 눌러도 됩니다. "Close" 로 닫으면 됩니다.
