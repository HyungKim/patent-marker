# 다른 PC 로 옮겨서 실행하기 ─ 설치·이전 안내

> **한 줄 요약**: 폴더를 통째로 복사하고 → `setup` 한 번 → `run` 으로 실행합니다.
> 클릭 단위로 따라 할 수 있는 버전은 [00_Windows_따라하기_가이드.md](00_Windows_따라하기_가이드.md) 입니다.
> 대상 PC 에 인터넷이 **있으면 A 경로**, **없으면 B 경로**를 따르세요.

---

## 0. 먼저 확인할 것 (대상 PC 요구 사양)

| 항목 | 최소 | 권장 | 비고 |
|---|---|---|---|
| OS | Windows 10 22H2 / macOS 12 | Windows 11 / macOS 14 | Linux 도 setup.sh 로 가능 |
| 메모리(RAM) | 16GB | 24GB 이상 | qwen3:14b 가 약 10GB 를 차지 |
| 저장 공간 | 15GB 여유 | 20GB | 모델 9GB + 라이브러리 + 작업 파일 |
| GPU | 없어도 됨 | Apple Silicon 또는 NVIDIA (VRAM 12GB+) | **아래 속도 표 참고** |
| 기타 | VS Code 설치됨 | | 터미널만 있어도 됩니다 |

### 속도는 GPU 와 메모리 대역폭이 좌우합니다

| 대상 PC | 5장짜리 보고서 기준 | 권장 모델 |
|---|---|---|
| Apple Silicon Mac (M1~M4) | 5~10분 | qwen3:14b |
| Windows + NVIDIA GPU (VRAM 12GB 이상) | 1~3분 | qwen3:14b |
| Windows + NVIDIA GPU (VRAM 8GB) | 5~10분 | qwen3:8b |
| **Windows, GPU 없음 (CPU 만)** | **30분~1시간 이상** | qwen3:8b 로 낮추세요 |

GPU 가 없는 Windows 노트북이라면 `run.bat` 대신 **`run_8b.bat`** 을 더블클릭하세요. 오프라인 꾸러미에는 qwen3:8b 도 들어 있습니다.

## 1. 무엇을 복사하나

### 복사할 것 ─ 프로젝트 폴더 전체
```
patent_marker/   ← 이 폴더를 통째로 (USB, 공유 폴더, 압축 파일 등)
```

### 복사하지 **않을** 것 (복사해도 소용없음)
| 폴더 | 이유 |
|---|---|
| `.venv/` | 파이썬 가상환경은 OS·경로에 묶여 있어 다른 PC 에서 동작하지 않습니다. setup 이 새로 만듭니다. |
| `__pycache__/` | 캐시. 자동 재생성됩니다. |
| `out_*.pptx` | 테스트 결과물. |

> 압축해서 옮길 때: `.venv` 를 빼면 전체 용량이 1MB 미만입니다 (오프라인 꾸러미 제외).

## 2. A 경로 ─ 대상 PC 에 인터넷이 **있을 때**

### Windows

1. 복사한 `patent_marker` 폴더를 엽니다.
2. **`setup.bat` 을 더블클릭**합니다. 검은 창이 뜨고 5단계가 차례로 진행됩니다.
   - Python 이 없으면 winget 으로 자동 설치 (이때 "사용자 계정 컨트롤" 창이 뜨면 **예**)
   - Ollama 가 없으면 winget 으로 자동 설치
   - 모델 9GB 다운로드 ← 회선에 따라 5~30분. **창을 닫지 말고 기다리세요.**
3. `설치 완료!` 가 보이면 아무 키나 눌러 창을 닫습니다.
4. **`run.bat` 을 더블클릭**합니다. 브라우저가 자동으로 열립니다. (안 열리면 주소창에 `http://127.0.0.1:8765`)

> winget 이 없는 구형 Windows 라면 setup.bat 이 안내 문구를 띄웁니다. 그 경우
> https://www.python.org/downloads/ 에서 Python 3.12 를 설치할 때 **"Add python.exe to PATH" 체크**,
> https://ollama.com/download 에서 Ollama 를 설치한 뒤 setup.bat 을 다시 실행하세요.

### macOS

터미널(응용 프로그램 > 유틸리티 > 터미널)을 열고:

```bash
cd ~/patent_marker
```

```bash
bash setup.sh
```

```bash
bash run.sh
```

Homebrew 가 없어도 됩니다. setup.sh 가 필요한 것을 직접 내려받습니다.

## 3. B 경로 ─ 대상 PC 에 인터넷이 **없을 때** (폐쇄망)

인터넷이 되는 컴퓨터(지금 이 Mac)에서 **설치 꾸러미**를 먼저 만들어 함께 가져갑니다.

### 3-1. 인터넷 되는 컴퓨터에서 (이 Mac)

대상 PC 가 Windows 면:

```bash
cd ~/patent_marker && bash tools/make_offline_bundle.sh windows
```

대상 PC 가 Apple Silicon Mac 이면:

```bash
cd ~/patent_marker && bash tools/make_offline_bundle.sh mac
```

`offline_bundle/` 폴더(약 10GB)가 프로젝트 안에 생깁니다. 내용물:

| 폴더 | 내용 |
|---|---|
| `wheels/` | 파이썬 라이브러리 (대상 OS 용) |
| `python/` | Python 3.12 설치 파일 |
| `ollama/` | Ollama 설치 파일 |
| `models/` | qwen3:14b 모델 파일 (약 9GB) |

### 3-2. 옮기기

`patent_marker` 폴더 전체(`offline_bundle` 포함, `.venv` 제외)를 USB 등으로 대상 PC 에 복사합니다.

### 3-3. 대상 PC 에서

- **Windows**: `setup_offline.bat` 더블클릭 → 끝나면 `run.bat`
  - Python 설치 화면이 뜨면 끝날 때까지 기다립니다 (자동 진행).
  - Ollama 설치 화면이 뜨면 **Install** 을 누릅니다.
- **macOS**: `bash setup_offline.sh` → 끝나면 `bash run.sh`
  - Python 설치 시 관리자 비밀번호를 묻습니다.

모델 파일은 `~/.ollama/models` (Windows: `C:\Users\사용자\.ollama\models`) 로 복사됩니다.
그 뒤로는 인터넷이 전혀 없어도 동작합니다.

## 4. VS Code 에서 쓰기

VS Code 는 **편집기**입니다. 실행 자체는 위의 setup/run 스크립트가 하고, VS Code 는 그것을 버튼으로 눌러 주는 역할입니다.

### 처음 한 번

1. VS Code 실행 → **파일 > 폴더 열기** → `patent_marker` 선택
2. 오른쪽 아래에 "권장 확장을 설치하시겠습니까?" 가 뜨면 **설치** (Python 확장)
   - 안 뜨면: 왼쪽 확장 아이콘(네모 4개) → `Python` 검색 → Microsoft 것 설치
3. 메뉴 **터미널 > 작업 실행(Run Task)** → **`1) 처음 한 번: 환경 설치`** 선택
   (인터넷 없으면 `1-오프라인)` 선택)
4. 설치가 끝나면 **Ctrl+Shift+P** (Mac: Cmd+Shift+P) → `Python: Select Interpreter` → `.venv` 가 붙은 항목 선택
   - 보통 자동으로 잡힙니다. 오른쪽 아래 상태줄에 `('.venv': venv)` 가 보이면 된 것입니다.

### 매번 실행

- 방법 ①: **터미널 > 작업 실행** → **`2) 프로그램 실행`** (Ollama 자동 시작 + 브라우저 열림)
- 방법 ②: 왼쪽 **실행 및 디버그(▶ 벌레 아이콘)** → 위쪽 드롭다운에서 **`▶ 특허 마킹 서버 실행`** → **F5**
  - 이 방법은 Ollama 를 자동으로 켜 주지 않으므로, 먼저 터미널에서 `ollama serve` 를 실행해 두세요.
  - 디버그 모드라 코드에 중단점을 찍고 한 줄씩 볼 수 있습니다.

### 종료

실행 중인 터미널 창에서 **Ctrl + C**. (Windows run.bat 은 창을 닫아도 됩니다.)

### 코드 수정 후 확인

**실행 및 디버그** 드롭다운의 `🧪 스모크 테스트` 를 F5 로 돌리면 모델 없이 몇 초 만에 파일이 정상 생성되는지 확인됩니다.

## 5. 주의사항

### 보안·폐쇄망
- 웹 서버는 `127.0.0.1` 에만 열립니다. 같은 PC 의 브라우저만 접속할 수 있습니다.
- 업로드한 파일은 OS 임시 폴더(Windows: `%TEMP%`, Mac: `/var/folders/...`)에 잠시 저장됩니다. 재부팅 시 정리됩니다. 민감 문서라면 작업 후 임시 폴더를 비우세요.
- **Ollama 데스크톱 앱**은 시작 시 업데이트 확인을 시도합니다. 완전 폐쇄망에서는 인터넷이 없으니 실패하고 넘어가지만, 보안 정책상 문제가 되면 앱 대신 터미널에서 `ollama serve` 만 쓰세요.
- 첫 실행 때 Windows 방화벽이 "python.exe 가 네트워크에 접근하려 합니다" 를 물을 수 있습니다. 127.0.0.1 통신뿐이므로 **허용**해도 되고 **취소**해도 동작합니다.

### 경로
- 프로젝트 폴더 경로에 **한글·공백**이 있어도 동작하지만, 문제가 생기면 `C:\patent_marker` 처럼 짧은 영문 경로로 옮겨 보세요.
- **OneDrive·Google Drive 동기화 폴더 안에는 두지 마세요.** `.venv` 의 수천 개 파일을 계속 동기화하려 해 느려지고 잠금 오류가 납니다.

### 실행
- **첫 분석이 유독 느립니다.** 모델 9GB 를 메모리에 올리는 데 30초~1분이 더 걸립니다. 그 뒤는 빨라집니다.
- 분석 중에는 **노트북이 잠자기에 들어가지 않게** 하세요 (전원 옵션).
- `추론 모드` 체크박스는 3~5배 느립니다. 꼭 필요할 때만.
- 메모리가 16GB 인 PC 에서 14b 모델이 "메모리 부족" 으로 멈추면 `qwen3:8b` 로 바꾸세요:
  `ollama pull qwen3:8b` 후, Windows 는 `set PM_MODEL=qwen3:8b` → `run.bat`, Mac 은 `PM_MODEL=qwen3:8b bash run.sh`
- 결과 파일은 **PowerPoint 2016 이상**에서 형광펜이 제대로 보입니다. 미리보기 앱에서는 밑줄과 `【특허검토필요】` 문구만 보일 수 있습니다.

## 6. 문제 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| 화면 상단이 빨간 점: "Ollama 에 연결할 수 없습니다" | Ollama 가 안 켜짐 | Windows: 시작 메뉴에서 Ollama 실행 또는 `run.bat` 재실행 / Mac: 터미널에서 `ollama serve` |
| "모델 qwen3:14b 이 없습니다" | 모델 미다운로드 | 인터넷 있으면 `ollama pull qwen3:14b`, 없으면 오프라인 꾸러미의 `models/` 복사 확인 |
| `setup.bat` 에서 "winget 은(는) 인식할 수 없는 명령" | 구형 Windows | Python·Ollama 를 공식 사이트에서 수동 설치 후 재실행 (2절 참고) |
| `python` 은 실행되는데 버전이 3.8 등으로 낮음 | 옛 Python 이 먼저 잡힘 | python.org 에서 3.12 설치 후 재실행. setup 이 `py -3.12` 를 우선 찾습니다 |
| 브라우저가 "연결할 수 없음" | 서버가 아직 안 뜸 / 포트 충돌 | 5초 후 새로고침. 계속되면 `set PM_PORT=8766` (Mac: `PM_PORT=8766 bash run.sh`) 로 포트 변경 |
| 분석이 몇 분째 0% | 첫 모델 로딩 중 | 1~2분 더 기다림. `ollama ps` 로 모델이 올라왔는지 확인 |
| "메모리 부족" / 매우 느림 | RAM 부족 또는 GPU 없음 | `qwen3:8b` 로 변경 (5절) |
| 한글 파일명 업로드 실패 | 드물게 브라우저 문제 | 파일명을 영문으로 바꿔 시도 |
| 결과 PPTX 열 때 "복구하시겠습니까?" | 원본에 특수한 요소 | 원본을 PowerPoint 에서 한 번 "다른 이름으로 저장" 한 뒤 다시 분석 |
| `.bat` 파일의 한글이 깨져 보임 | 콘솔 글꼴/코드페이지 | 동작에는 영향 없음. 메시지만 깨진 것. 굳이 고치려면 창 제목 우클릭 > 속성 > 글꼴을 "굴림체" 로 |

## 7. 설치가 잘 됐는지 확인하는 순서

1. 터미널(또는 VS Code 터미널)에서 프로젝트 폴더로 이동
2. 아래 명령이 `8/8 통과` 를 출력하면 파이썬 환경 OK

   Windows
   ```
   .venv\Scripts\python tests\test_filter.py
   ```
   macOS
   ```bash
   .venv/bin/python tests/test_filter.py
   ```

3. 아래 명령이 `out_smoke.pptx` 를 만들면 PPTX 읽기·쓰기 OK (모델 불필요)

   Windows
   ```
   .venv\Scripts\python tests\smoke.py
   ```
   macOS
   ```bash
   .venv/bin/python tests/smoke.py
   ```

4. `ollama list` 에 `qwen3:14b` 가 보이면 모델 OK
5. `run` 으로 화면을 열고 `samples/회사보고자료_예시.pptx` 를 올려 끝까지 돌려 보기
   - 결과가 어떤 모양인지 미리 보려면 `samples/회사보고자료_예시_마킹결과.pptx` 를 PowerPoint 로 열어 보세요 (이 Mac 에서 실제 모델로 만든 것)

여기까지 되면 이전이 끝난 것입니다.
